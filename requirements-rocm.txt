# requirements-rocm.txt — x86_64 Windows + AMD GPU (gfx1030)
#
# Package set derived from the script imports (33 .py files scanned): numpy,
# scipy (scipy.io.loadmat), h5py (.mat v7.3), matplotlib, torch — nothing else.
# No pandas/sklearn/tqdm/seaborn are imported anywhere in the repo.
#
# ── Torch-with-ROCm on Windows (gfx1030) ─────────────────────────────────────
# The official pytorch.org ROCm indexes are Linux-only, but Windows ROCm torch
# wheels DO exist from two sources (both need Python 3.12, cp312):
#
#   (1) AMD official — ROCm 7.2.1 at repo.radeon.com (recommended). Install the
#       ROCm SDK wheels + the torch trio directly by URL:
#         pip install --no-cache-dir ^
#           https://repo.radeon.com/rocm/windows/rocm-rel-7.2.1/rocm_sdk_core-7.2.1-py3-none-win_amd64.whl ^
#           https://repo.radeon.com/rocm/windows/rocm-rel-7.2.1/rocm_sdk_devel-7.2.1-py3-none-win_amd64.whl ^
#           https://repo.radeon.com/rocm/windows/rocm-rel-7.2.1/rocm_sdk_libraries_custom-7.2.1-py3-none-win_amd64.whl ^
#           https://repo.radeon.com/rocm/windows/rocm-rel-7.2.1/rocm-7.2.1.tar.gz
#         pip install --no-cache-dir ^
#           https://repo.radeon.com/rocm/windows/rocm-rel-7.2.1/torch-2.9.1+rocm7.2.1-cp312-cp312-win_amd64.whl ^
#           https://repo.radeon.com/rocm/windows/rocm-rel-7.2.1/torchaudio-2.9.1+rocm7.2.1-cp312-cp312-win_amd64.whl ^
#           https://repo.radeon.com/rocm/windows/rocm-rel-7.2.1/torchvision-0.24.1+rocm7.2.1-cp312-cp312-win_amd64.whl
#       Requires the ≥26.2.2 Adrenalin driver. Verify:
#         python -c "import torch; print(torch.cuda.is_available())"   # → True
#
#   (2) Community builds — guinmoon/rocm7_builds on GitHub (TheRock-based;
#       the Chatterbox-TTS-amd stack). gfx103X-all wheels from the release
#       page, installed from local files:
#         pip install "rocm-7.1.1.tar.gz" rocm_sdk_core-7.1.1*.whl rocm_sdk_devel-7.1.1*.whl rocm_sdk_libraries_gfx103x_all-7.1.1*.whl
#         pip install torch-2.9.1+rocmsdk20251207-cp312-cp312-win_amd64.whl torchaudio-2.9.0+rocmsdk20251207*.whl torchvision-0.24.0+rocmsdk20251207*.whl
#       Known gfx103X-Windows quirk: disable cudnn (HIP 0xC0000005 crash).
#
# After the ROCm/torch stack is in place, the rest installs from PyPI normally:
#   pip install -r requirements-rocm.txt
#
# The scripts' device selection (`train_*.py`, `case30_common.py`) was written
# for CUDA. ROCm wheels surface the GPU as 'cuda' via HIP, so most code runs
# unchanged — but check .cuda() calls / cudnn settings when porting.

# ── Base dependencies ────────────────────────────────────────────────────────
